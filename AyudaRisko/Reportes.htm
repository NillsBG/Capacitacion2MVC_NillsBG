Ayuda — Módulo de Reportes

Esta sección explica cómo usar la pantalla de Mantenimiento de Reportes y la ventana de vista previa e impresión asociada, incluida en el sistema como parte del componente Reportes.

1. Pantalla principal (Mantenimiento de Reportes)

Muestra el listado de todos los reportes registrados y permite buscar, crear, editar, borrar e imprimir cada registro.

Elemento Función
Buscar Filtra la tabla de reportes por nombre a medida que se escribe.
Tabla de resultados Lista todos los reportes registrados. Seleccione una fila antes de Editar, Borrar o Imprimir.
Nuevo Habilita el formulario de ingreso para registrar un reporte nuevo.
Editar Carga los datos de la fila seleccionada en el formulario para modificarlos.
Grabar Guarda el reporte nuevo o los cambios del reporte en edición.
Borrar Elimina el reporte seleccionado, previa confirmación.
Imprimir Abre la ventana de vista previa del reporte (ver sección 3).

2. Campos del formulario

Campo Descripción Obligatorio
Nombre Nombre descriptivo del reporte. Sí
Tipo Categoría o tipo de reporte. Sí
Descripción Detalle adicional sobre el contenido del reporte. No
Id Usuario Identificador numérico del usuario que generó el reporte. Sí (numérico)
Nota: el campo Id Usuario debe contener únicamente números. Si se ingresa un valor no numérico, el sistema muestra un aviso y no permite grabar.

3. Ventana de vista previa e impresión

Al presionar Imprimir se abre una ventana independiente que muestra el reporte generado con Microsoft ReportViewer, con controles para paginar, buscar, exportar y enviar a imprimir.

  1. Seleccione un reporte en la tabla principal.
  2. Presione el botón Imprimir.
  3. En la ventana que se abre, use la barra de herramientas superior para navegar entre páginas, hacer zoom, exportar a PDF/Excel o imprimir directamente.

4. Solución de problemas frecuentes

"No se ha especificado la definición del informe"
Ocurre cuando el nombre del recurso incrustado no coincide con el archivo .rdlc real, o cuando ese archivo no tiene su propiedad Build Action configurada como Embedded Resource.
"No se ha proporcionado ninguna instancia de origen de datos para el origen de datos '...'"
El nombre usado al crear el ReportDataSource en código no coincide con el nombre del DataSet definido dentro del archivo .rdlc. Verifique el nombre exacto en el panel "Datos del informe" del diseñador del reporte.

Si el problema persiste después de verificar ambos puntos, contacte al encargado del componente Reportes.
